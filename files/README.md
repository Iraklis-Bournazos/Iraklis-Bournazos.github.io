# Report PDFs

Drop a PDF here, then add one line to the project's file in `content/projects/`:

    report: EI2525_multicriteria_load_control.pdf

A "Read the full report (PDF)" button appears on that project's page.

Keep files under ~10 MB. If a PDF is larger, compress it first:

    # macOS, no install needed
    /System/Library/Automator/*Quartz*/Contents/Resources/*.py --help
